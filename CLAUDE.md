# «Каспийский след» — фронтенд

Доказательный инструмент для журналистов и эко-НКО: показывает участок вероятного
происхождения загрязнения и версии, исключённые фактами. Никогда не называет виновника.
ТЗ и рабочий промпт фронтендера прикладываются к чату отдельными файлами.

## Зона ответственности
Только фронтенд: схема реки, лента сигналов, правая панель, реплей, печатное досье,
экран «недостаточно данных» (Актау). Бэкенд (Express/SQLite) и investigation-core
пишут двое других разработчиков — их код не трогаем и не предлагаем.

## Стек
React 19 + TypeScript strict + Vite 8, Tailwind 4, shadcn/ui на **Base UI**
(`@base-ui/react`, стиль base-lyra), TanStack Query (серверное состояние),
Zustand (только состояние реплея), react-router-dom (одобрен в аудит-сессии).
MapLibre — только после подтверждённых координат и при запасе времени.

### Base UI ≠ Radix
- Композиция через проп `render`, не `asChild`; части Dialog — `Popup`/`Backdrop`, не `Content`/`Overlay`.
- Импортов `@radix-ui/*` в проекте быть не должно.
- API компонентов сверять по `src/components/ui` и докам Base UI, не по памяти.
- Новые компоненты: `npx shadcn@latest add <name>` — свободно, без спроса.

## Жёсткие запреты
1. Никаких выдуманных данных — только числа из таблиц ТЗ §5 (май и сентябрь 2025).
2. Никаких выдуманных координат — до подтверждения только линейная схема реки.
3. Никаких обвинительных формулировок: запрещены «виновен», «нарушитель»,
   «источник установлен», «доказано». Всегда — «объект для проверки».
4. Никакой красно-зелёной шкалы «опасности» — цвет отражает только относительное
   положение значения внутри выбранного события.
5. «Недостаточно данных» — полноценное состояние, не ошибка. Экран Актау — часть демо.
6. Фронт не считает выводы: L0–L3, коридор, delta приходят с бэка
   (или из заглушки с готовым результатом).
7. Тяжёлые зависимости — только с согласия (кроме shadcn-компонентов).

## Конвенции
- Типы 1:1 из ТЗ §8 в `src/types/` — до появления `packages/shared`.
- Константы в `src/constants/`: `UPPER_SNAKE_CASE` для скаляров; справочники
  (`EVIDENCE_LEVEL_META`, `PHENOMENON_LABELS`) — camelCase-ключи, `as const`.
  В JSX ни магических чисел, ни зашитых лейблов статусов.
- Заглушки ТОЛЬКО в `src/api/`: помечены `// STUB:`, занесены в `docs/stubs.md`,
  делают разовый `console.warn('STUB: ...')`, значения — реальные из ТЗ §5.
- Сквозные примитивы (`MeasurementValue`, `SourceLink`, `EvidenceLevelBadge`,
  `InsufficientData`) делаются ДО экранов.
- Числа — `Intl.NumberFormat('ru-RU')` (0,234), даты — явно в поясе +05:00.
- Комментарии — только неочевидные «почему».

## Режим работы
Одна большая задача за сессию. В начале сессии: прочитать `docs/frontend-plan.md`
и `docs/decisions.md`, доложить 2–3 строками (где остановились, что берём, чего
не хватает), дождаться подтверждения — и только потом писать код. В конце сессии:
обновить `docs/frontend-plan.md`, `docs/decisions.md`, `docs/stubs.md`, сделать
осмысленный коммит. Перед началом — `git pull`.

## Команды
`npm run dev` / `build` / `typecheck` / `lint` / `format`
