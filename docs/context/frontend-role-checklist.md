# Этапы F0–F9 плана роли и наше фактическое состояние

Обновлено: 04.08.2026 (после сессии 11). Источник этапов —
`docs/caspian-trace-role-frontend.md` §6–§15. Часы там — время хакатона,
у нас нумерация идёт сессиями; сверяем по составу работ, не по часам.

| Этап | Состав | У нас |
|---|---|---|
| **F0** подготовка | ветка `feat/frontend-mvp`, чтение доков, зелёные typecheck/lint/build, три кейса открываются | Сделано, **кроме ветки**: работаем в `main` (до присланного плана в репо был один разработчик) |
| **F1** реплей | store, playback, projection, play/pause/seek/reset, клавиатура, синхронные колонки | Сделано в сессиях 9–10. Не хватает: **drag шкалы** (есть click+клавиатура), **`prefers-reduced-motion`**, кнопки **reset** отдельно от «запустить заново» |
| **F2** API-слой | `VITE_DATA_MODE`, Zod, `AbortSignal`, timeout, нормализованная ошибка, фабрика query keys | Контрактные правки форм данных сделаны (сессия 11); сам слой — **не начат** |
| **F3** интеграция read API | `VITE_DATA_MODE=api`, Vite proxy, сверка чисел с seed | Ждёт бэк (контрольная точка C) |
| **F4** досье | `/dossier/:id`, 12 секций, печать A4, «Скачать JSON» | **Следующая задача** (сессия 12). Состав секций пересмотрен по новому ТЗ |
| **F5** evidence/replay/export API | подключение по одному, обновление `docs/stubs.md` | Ждёт бэк (контрольная точка D) |
| **F6** состояния источников | healthy/degraded/rate-limited/failed/cache/last success + проверка отказов | **Не начато** |
| **F7** UX и доступность | 1280×720 и 1440×900, темы, клавиатура, фокус, контраст, отсутствие layout shift | Частично: 1280×720 и обе темы проверяются каждой сессией через Playwright |
| **F8** тесты | unit (store, projection, форматирование, `sourceHref`, уровни, insufficient-data) + E2E из 10 шагов | **Не начато, инфраструктуры нет** |
| **F9** freeze и демо | production build, чистая консоль, отсутствие `STUB:` в API-режиме, 5 прогонов, резервное видео | Не начато |

## Definition of Done фронтенда (роль §18)

- [ ] Все изменения в разрешённой зоне файлов.
- [x] Реплей работает с pause/seek/reset.
- [x] Все колонки синхронизированы одной projection.
- [ ] API и seed режимы переключаются env-переменной.
- [ ] Все обязательные endpoints подключены.
- [x] Нет вычисления delta/L0–L3/corridor во фронте.
- [x] Сентябрь, май и Актау отображаются корректно.
- [ ] Досье открывается и печатается.
- [x] Каждое число ведёт к источнику.
- [ ] Ошибки источника отличаются от отсутствия событий.
- [x] Typecheck, lint и build зелёные.
- [ ] Критический E2E зелёный.
- [x] 1280×720 проверено.
- [x] Seed fallback проверен без бэкенда (сейчас это единственный режим).
- [ ] Трёхминутное демо отрепетировано.
