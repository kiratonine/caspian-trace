# Источники истины и их приоритет

Обновлено: 04.08.2026, после переезда фронта на `packages/contracts` (сессия 13).

## Приоритет документов

0. **`packages/contracts`** (код, не документ) — Zod-схемы и фикстуры всех
   эндпоинтов. С сессии 13 форма данных берётся отсюда, а не из наших описаний:
   схема исполняется, поэтому расхождение видно сразу, а не на интеграции.
   Владелец — Full-stack 1, правки только через него. Фикстуры
   `packages/contracts/fixtures/*.json` — эталон значений; там, где они
   расходятся с нашим сидом, правы они.
1. **`docs/caspian-trace-role-frontend.md`** — план моей роли: зона файлов,
   этапы F0–F9, критерии приёмки, Definition of Done фронтенда.
   При конфликте с чем угодно — прав этот документ.
2. **`docs/caspian-trace-development-roadmap.md`** — общий план команды:
   контракты REST API (§9), общие технические решения (§4), состав досье (§21),
   реплей (§20), тесты (§23), демо (§29), распределение работы (§27).
3. **`CLAUDE.md`** — конвенции и жёсткие запреты проекта. Запреты 1–7
   (никаких выдуманных данных, координат, обвинительных формулировок,
   «шкалы опасности»; фронт не считает выводы) обновлением ТЗ не отменены.
4. **`docs/spec.md`** — исходное ТЗ. Предметная часть актуальна и остаётся
   основанием для всех формулировок.
5. **`docs/frontend-prompt.md`** — рабочий промпт фронтендера, вводный документ.

## Зона ответственности (роль §2)

Единолично редактирую: `apps/web/**`, `docs/frontend-plan.md`, `docs/stubs.md`
(+ `docs/decisions.md` и `docs/context/**` — рабочая память фронтенда,
роадмап §28 требует обновлять её перед merge).

Не трогаю: `apps/api/**`, `packages/**`, `data/verified/**`,
`package-lock.json` (владелец — Full-stack 1).

Новая зависимость — только через Full-stack 1: он добавляет её в общий
bootstrap-commit и обновляет lockfile. Исключение прежнее: компоненты
`npx shadcn@latest add` ставятся без спроса, но если команда добавит пакет
в зависимости — сначала написать Full-stack 1.

**Исключение сессии 13:** в `apps/web/package.json` добавлена workspace-зависимость
`@caspian-trace/contracts: 0.0.1` (по образцу `apps/api`), из-за чего изменился
и `package-lock.json`. Без этого переезд на общие контракты невозможен;
Full-stack 1 нужно об этом сказать, чтобы правка не потерялась в его следующем
общем коммите. Новых внешних пакетов не добавлено: zod приезжает транзитивно
внутри `@caspian-trace/contracts`, и во фронте он нигде не импортируется напрямую.
