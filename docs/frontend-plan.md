## Подводные камни (сверх раздела 8 промпта; полный аудит — сессия 1)
- Таймеры реплея: от `performance.now()` с хранимым offset; пауза/seek сбрасывают таймеры;
  цепочка `setTimeout` дрейфует. ← СНЯТО сессией 9: позиция хранится парой якорей,
  таймер один и всегда до абсолютного `offsetMs` следующего шага.
- TanStack Query и реплей не смешивать: панели читают состояние текущего шага из селектора
  replayStore поверх загруженных данных, без рефетча на шаг. ← СНЯТО сессией 9
  (`useReplayFrame` + `projectDetailForReplay`).
- Длинный текст в строке-плеере распирает грид: строке грида нужен `min-w-0`, иначе её
  минимальная ширина считается по содержимому и появляется горизонтальная прокрутка.
  Проверять `scrollWidth > clientWidth` на 1280×720 после каждой правки футера.
- ~~`.prettierrc` расходится с кодовой базой~~ СНЯТО 04.08.2026: разовый прогон
  `prettier --write` по `apps/web` выполнен отдельным коммитом, добавлен
  `.gitattributes` (`* text=auto eol=lf`) — `npm run format` теперь безопасен,
  и конфликта концов строк на разных ОС не будет.
- Печать из тёмной темы: браузер не печатает фоны, поэтому светлый текст ложится белым
  по белому. Лечится в `@media print` подменой переменных тем — но только переменных:
  утилиты с `dark:`-вариантом (палитра уровней) требуют отдельной print-пары. ← СНЯТО
  сессией 12 для `EvidenceLevelBadge`; при добавлении новых цветных классов проверять.
- Base UI `Button render={<Link/>}` рендерит `<a role="button" tabindex="0">`: ссылка
  объявляется кнопкой, ломается «открыть в новой вкладке». Для навигации — `Link`
  с `buttonVariants(...)`, компонент `Button` только для настоящих кнопок.
- PDF-якоря `#page=N` зависят от заголовков сервера Казгидромета — проверить реальные URL;
  фолбэк: попап с `sourceExcerpt` + номер страницы текстом.
- Длинные подписи створов («0,5 км ниже сброса ГКП "Атырау су арнасы"») — сокращение + тултип;
  тултипы Base UI над SVG проверить в первый день схемы. ← СНЯТО сессией 5:
  схема — DOM/flex, не SVG. Сессия 12: тултип с полным именем убран — он дословно
  повторял видимую подпись; осталось усечение, полные имена есть в панели и досье.
- Тултип, дублирующий видимый текст, — шум, а не подсказка. И открываться он должен
  вниз: сверху попап накрывает строку, на которую наведён курсор (`side="bottom"`
  по умолчанию в `components/ui/tooltip.tsx`).
- Кнопка в шапке колонки выше строки заголовка и растягивает шапку: линия `border-b`
  разъезжается с соседними колонками. Лечится `-my-1` на кнопке, а не изменением
  `py` — высота шапок (41 px) общая для всех трёх колонок.
- Deep-link: выбранное расследование и месяц в URL (защита: открыть экран закладкой, пережить F5).
- Печать проверять в блоке 36–45, не в последний час.
- Всё офлайн: никаких CDN (шрифт уже локален; тайлы карт — аргумент против MapLibre).
- React 19 / Vite 8 / TS 6 / ESLint 10 — примеры из интернета устарели в обе стороны,
  сверяться с установленными версиями.
- Зелёная проверка может ничего не проверять: `tsc --noEmit` на solution-конфиге
  (`"files": []` + `references`) молча компилирует ноль файлов. Нужен режим сборки
  (`tsc -b`). Сомневаешься в команде — сломай код намеренно и убедись, что она падает.
